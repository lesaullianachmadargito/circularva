# CircuLarva

Storefront for CircuLarva: whole dried black soldier fly larvae raised on snake fruit (salak) waste in Sleman, Yogyakarta, Indonesia.

Live site: https://lesaullianachmadargito.github.io/circularva/

Static HTML, CSS and JavaScript. No build step, no backend: the quote list is kept in the browser and sent by WhatsApp or email.
